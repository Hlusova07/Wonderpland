# Wonderpland — Модель данных

## Сущность Task

Задача пользователя хранится в таблице `tasks`.

| Поле | Тип | Ограничения | Описание |
|------|-----|-------------|----------|
| id | Integer | Primary Key, Index | Уникальный идентификатор |
| title | String(255) | Not Null | Название задачи |
| completed | Boolean | Not Null, Default=False | Статус выполнения |

## Связи

На текущем этапе используется одна сущность — `Task`.

В будущих версиях планируется добавить:

- User — пользователь;
- Habit — привычка;
- Note — заметка;
- Finance — финансовая операция;
- Reading — запись о прочитанной книге;
- CalendarEvent — событие календаря.

После добавления пользователей задачи могут быть связаны с конкретным пользователем через внешний ключ `user_id`.
